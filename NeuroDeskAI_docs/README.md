# NeuroDesk AI

NeuroDesk AI, telefon gorusmeleri, e-postalar, takvim etkinlikleri, notlar, belgeler ve resmi entegrasyonlarla erisilebilen mesajlasma verilerini analiz eden AI destekli kisisel/kurumsal calisma asistani projesidir.

Bu repo su an urun ve teknik tasarim dokumanlarini icerir. Uygulama kodu henuz uretilmemistir.
